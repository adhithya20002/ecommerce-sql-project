# E-Commerce SQL Project

## Overview
This project analyzes e-commerce data using SQL.

## Analyses Done
- Revenue analysis
- Customer segmentation (RFM)
- Cohort analysis
- Product performance

## Key Insights
- Revenue changes monthly
- Few customers generate most revenue
- Retention drops after first purchase
- Some products have high returns

## Recommendations
- Improve customer retention
- Focus on high-value customers
- Reduce returns
